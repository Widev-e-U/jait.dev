Built for the whole task

From first prompt to reviewed change.

Jait brings the parts of a coding session into view, so you can follow the work and steer it while it happens.

Parallel chat panels

Open multiple chats in the same project and resize the panels as work moves forward.

Ask in parallel

Fork a chat into branch conversations to explore alternatives without losing the original thread.

Live tool terminals

Read terminal output inside running tool cards, then revisit the result in the chat history.

Source control in view

Inspect changed files and diffs from the project sidebar as the agent edits code.

Provider usage

Guarded actions
